# 우주 모드 그림 명세 (STYLE='cosmic') — art_spec_v2/v3/v4와 함께 주되, 아래가 충돌하면 이 문서가 우선

적용: 우주과학 대본. `config.py`에 `STYLE = 'cosmic'`, `PAL_DEFAULT = 'nebula' | 'aurora' | 'deepfield' | 'solar'` (장면별 `PAL`로 섞기 가능, 최대 3개).
화풍은 **면과 빛 중심 + 얇은 스케치 선 유지**(사용자 결정 2026-10-12: 두 방식 혼합). 기본 모드 규칙 중 바뀌는 것만 적는다.

1. **배경은 밤(`night_*`)이 70% 이상.** 종이·노을은 도입·결말의 현대 일상 장면에만.
2. **성운 층(필수)**: 방사형 그라데이션(`radialGradient`) 3~4장을 크게(캔버스의 40~90%) 겹친다. 색은 팔레트 `accents`와 `night_glow`, 불투명도 0.15~0.55, 가장자리는 투명으로 끝나게(`stop-opacity 0`). **SVG `<filter>`(블러 등)는 금지**(렌더 속도). 흐림은 그라데이션 정지점으로만 낸다.
3. **별 3단계**: ① 작은 별 120~250개(반지름 0.8~1.6px, 불투명도 0.4~0.9) ② 중간 별 12~25개(2.5~4px, 그룹 `mv-glint-s1`, `mv-glint-s2`, `mv-glint-s3`로 나눠 반짝임 시차) ③ 큰 별 2~4개(십자 광채: 가는 선 4개 + 방사형 글로우). 별 위치는 가운데 물체(960,500)와 핵심 대상을 피한다.
4. **천체**: 구는 `radialGradient` 두 겹(본체 + 대기 글로우)과 한쪽 가장자리의 **림 라이트**(밝은 얇은 호)로. 그림자 쪽은 팔레트 `night_bottom`보다 어둡게. 표면 질감은 해칭 몇 줄. 얇은 스케치 윤곽선(2.5~3px, `night_line`)은 주인공 천체에만 둔다.
5. **빛줄기·궤도**: 궤도는 `night_line` 불투명도 0.35 점선/가는 선(동심원 금지 규칙 유지: 궤도는 내용상 필요할 때만, 이웃 컷과 같은 배치 금지). 빛줄기는 가는 사다리꼴 그라데이션 1~3개.
6. **가운데 물체(3-2)** 는 그대로: (960,500) 지름 170~260px의 밝은 천체·눈·렌즈 등, `mv-glint-core`.
7. **모션 그룹 추가** (기존 `mv-` 규칙에 더함): `mv-glint-s*` 별 반짝임, `mv-drift-nebula` 성운 층 하나를 ±25px 아주 느리게(20초 주기), `mv-orbit-*` 작은 천체가 궤도 위를 이동(그룹 회전, 중심은 궤도 중심), `mv-pulse-core` 별·태양의 밝기 맥동. 장면당 `mv-` 그룹 4~8개.
8. **금지(유지)**: 그림 안 글자, 균일한 굵은 검정 외곽선, 3D·실사, 사실과 다른 천체 묘사(크기 비율이 중요한 장면은 대본 숫자를 따르고 아니면 "not to scale"로 두지 말고 상징적으로 그림). 실제 사진 복제 금지.
9. 팔레트별 쓰임: `nebula` 성운·은하·별 탄생 / `aurora` 행성 대기·자기권·태양풍 / `deepfield` 먼 은하·블랙홀·우주 규모 / `solar` 태양·초신성·플레어.

## 효과음 (우주 모드 추가분, 모두 음정 없음, 파도처럼 길게 부풀었다 사그라드는 소리는 쓰지 않음)
`sparkle`(별빛 입자: 별·빛 등장), `bloom`(빠르게 퍼졌다 짧게 사라짐: 플레어·별 탄생), `starfall`(떨어지는 빛 꼬리: 유성), `pulse`(짧은 둥근 박동: 신호·맥동), `warp`(0.3초 날카로운 스침: 장소 이동), `glimmer`(아주 작은 반짝임 군집).
`riser`, `sweep`는 느리게 부풀었다 줄어드는 잡음이 파도 소리처럼 들려서 뺐다. 기본 25종 중 같은 성격의 `hush`, `breath`, `wind`, `rain`, `swish`는 우주 영상에서 쓰지 않는다(`wind`는 행성 대기 장면에서도 금지). 사이드카 `sfx.name`은 위 6종과 `tick`, `click`, `pop`, `drip`, `pencil`, `page`, `woodblock`, `stone`, `step`, `cloth` 중에서 고른다. 우주 영상은 단위의 35~45%에 효과음, 연속 두 컷에 같은 이름 금지.
