# tromelin-sandbank 대본 점검 (2026-11-09)
길이: 롱폼 원문 약 2,250단어 → 1,907단어(분당 145 기준 약 13.2분 + 아웃트로, 음성 실측 전). 숏츠 5편 300/311/319/321/373단어(≈2:04~2:34). 구독 요청 없음. 원문 5개 숏츠는 롱폼 문단을 그대로 쓰고 훅·마무리만 새로 씀.
조사: archaeology.org(Patel 2014) + Wikipedia "Tromelin Island" 본문 대조. 확인 못 한 것: 원 논문/프랑스어 1차 사료, 보트 정원, 불 15년 유지의 1차 근거, 총승선 인원(자료마다 다름).
