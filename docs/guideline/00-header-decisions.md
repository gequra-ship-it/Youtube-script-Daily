# 주요 결정 연표 (이력 전용)

> 최종 수정: 2026-11-14 · 이 파일은 **언제 무엇을 정했는지**만 적는 연표다. 규칙 자체는 각 장에 있고, 이 파일과 장이 다르면 장이 맞다. 새 결정은 날짜 순서에 맞는 자리에 한 줄로 넣는다(모두 2026년).

## 이 지침서의 근거와 표기
- 사용자가 **대본**을 주면 지침서의 규칙대로 산출물을 만든다(12장).
- 근거: 참고 채널 영상 3편 측정(10-08: 말투·구성·오디오·칠판·자막)과 사용자가 준 32초 모션 영상(10-09: 화풍·카메라·전환).
- 기본 방식은 SVG 모션그래픽(`tools/build/build3.py`). 20장이 3~4장·19장보다 우선한다.
- 수치는 1920×1080 기준. **(추정)** = 눈으로 판단, **(환산)** = 한국어 참고 영상 값을 영어용으로 바꾼 것(영어 영상 실측 아님), **(채널 결정)** = 참고 영상과 다르게 Miya's Note가 정한 값.
- 검증 기록·옛 규칙·3D 실험 상세를 담은 옛 전문은 브랜치 `archive/miyas-lab-2026-10-24`의 `docs/archive/guideline-full-2026-10-18.md`.
