# Miya's Lab 모션그래픽 제작 지침 (참고 스타일: 사용자 제공 모션 영상 + 인류의서재 일부)

> 이 문서는 Claude 프로젝트의 지침/지식 파일입니다. 사용자가 **대본**을 주면 이 문서의 규칙대로 산출물을 만듭니다(12장). **현행 규칙만 담은 요약본**이며, 검증 기록·옛 규칙·3D 실험 상세를 포함한 전문은 `docs/archive/guideline-full-2026-10-18.md`에 있습니다.
>
> 근거: 참고 채널 영상 3편 측정(2026-10-08, 말투·구성·오디오·칠판·자막)과 사용자가 준 32초 모션 영상(2026-10-09, 화풍·카메라·전환). **기본 방식은 SVG 모션그래픽(`tools/build3.py`, 2026-10-16 복귀)**, 20장이 3~4장·19장보다 우선.
>
> 수치는 1920×1080 기준. **(추정)** = 눈으로 판단, **(환산)** = 한국어 참고 영상 값을 영어용으로 바꾼 것(영어 영상 실측 아님), **(채널 결정)** = 참고 영상과 다르게 Miya's Lab이 정한 값.
