## 3. 일러스트 스타일 (새 레퍼런스 기준, 2026-10-09 사용자 결정, 2026-10-16 다시 기본)

**하지 않는 것**: 굵은 검정 외곽선·플랫 컬러(참고 채널 화풍), 동심원·방사선 배경(2026-10-10), 보라·마젠타·주황 기본값, 흰 배경 위 네온, 3D·실사·치비·과장된 만화 표정.

### 3-1. 화풍
- **배경은 장면마다 하나**: 종이(`paper_base`, 가는 연필 선) / 밤(`night_top`→`night_bottom`, 은은한 비네팅) / 노을(`dusk_stops` 3색). 색은 영상 팔레트에서(3-5). 영상 전체에서 섞되 한쪽이 절반을 넘지 않게.
- **선**: 얇은 손그림 선 2.5~4px(주인공만 6px까지), 곡선은 약간 흔들리게. 종이는 `paper_ink`, 밤은 `night_line`·`night_glow`.
- **음영**: 큰 형태는 부드러운 그라데이션·글로우, 질감은 해칭. 팔레트 강조색 4개를 주로.
- **인물**: 단순하고 품위 있는 실루엣, 점 눈, 절제된 표정, 다양한 피부색. **사람 비율·팔·손 (2026-10-17, `tools/art_spec.md` 6A·6B)**: 귀여운 비율(성인 5.5등신·아이 4.5등신, `tools/body.py`의 `kind='cute'` 기본), 팔은 관절이 보이지 않는 한 덩어리 곡선(`body.arm`), 팔꿈치는 아래팔이 실제로 움직일 때만(`elbow_moves=True`). 보이는 손은 모두 `tools/hands.py`(해부학 비율 6자세)로, 기본은 둥근 손이고 손가락은 필요한 장면(가리키기·쥐기·손 흔드는 클로즈업·손이 주제·손 자국)에서만. 사람 팔 움직임은 `mv-limb`(꼬리처럼 휘는 `mv-chain` 금지).
- 그림(SVG) 안에는 글자·숫자를 그리지 않는다(간판 포함). 글자는 3-6 화면 텍스트 층으로.

### 3-2. 물체 위치 규칙 (2026-10-22 사용자 결정: 가운데 원형 고정 해제)
- **가운데 둥근 물체는 필수가 아니다.** 주인공 물체는 어느 위치(왼쪽 x≈400, 오른쪽 x≈1500, 곡선 경로 위 등)에 있어도 되고, 둥글지 않아도 된다(종이비행기·모래시계·열쇠·자물쇠·도미노·막대·비커·우주선 등). 장면 의미에 맞는 모양과 위치를 고른다.
- 가운데 둥근 물체(정중앙 (960, 500), 지름 170~260px, `mv-core-<타입>` 19종, 4-1)를 쓰는 그림은 예전처럼 둔다. 쓰면 가운데에 중요한 것을 겹쳐 놓지 않고, 가능하면 다음 장면의 물체와 닮게(모양 겹치기 `match`, 4-3).
- 가운데 물체가 없는 그림은 `match`·`zoom`(가운데 확대) 전환의 효과가 약하므로, 빌드의 자동 선택에 맡기되 5종 새 전환(4-3)과 포커스 `focus` 확대를 우선한다.
- 배경은 장면 내용에 맞게 그림마다 따로(방, 풍경, 실험실, 현미경 시야, 노트, 타임라인 등). 이웃 컷과 같은 종류가 이어지지 않게, 12컷 중 같은 종류는 2컷 이하(`tools/art_spec.md` 5절).
- 움직이는 것은 `mv-` 그룹으로 그린다(4-1 객체 모션 12종 + 인물·사물 모션 + 코어 19종).

### 3-3. 소재와 연출 규칙
- 시대·장소를 정확하게(복식, 건물). 확인 안 된 디테일은 그리지 않는다.
- 도입·결말에 현대 일상 앵커(영어권 시청자 기준, 주제가 한국일 때만 한국 장면).
- 대본의 비유를 그대로 그림으로(자물쇠=종 장벽, 저울=득실).
- 과학 개념은 같은 화풍의 도해. 실존 인물 사실 묘사 금지. 실제 민족은 존엄하게. 죽음·식인·폭력은 분위기와 상징으로만.

### 3-4. 이미지 생성 프롬프트 템플릿 (영어, 생성 도구용)
```
soft 2D editorial illustration, thin hand-drawn ink lines, subtle hatching, soft gradients and gentle glow,
[paper background in palette paper_base | night background palette night_top->night_bottom | dusk gradient palette dusk_stops]  (colours from the video's palette, see 3-5),
one bright focal object (position per guideline 3-2; a round object at the centre is optional), calm dignified figures, 16:9, no text,

```
네거티브: `thick black outline, flat cartoon, 3d render, photorealistic, anime, chibi, neon on white, watermark, text, concentric rings, radiating lines, sunburst rays`

### 3-5. 색 팔레트 (사용자 결정 2026-10-10: "색감이 보라색 아니면 주황색이다. 대본에 맞게 색감을 사용하자")

`tools/palettes.py`: `ocean`(바다·심해·강) · `forest`(숲·습지·식물·곤충) · `desert`(사막·사바나·불) · `ice`(극지·빙하·고산) · `lab`(과학·의학·데이터) · `history`(역사·옛 도시·배·고고학) · `space`(우주·물리·시간, 남색+금, 보라는 성운일 때만) · `storm`(전쟁·재난·날씨·산업) · `body`(인체·동물 생물학·음식) · `sunset`(노을·꿈·판타지에만, 기본값 아님). 우주 4종은 3-7.
- 팔레트마다 종이(`paper_base`, `paper_ink`), 밤(`night_top`, `night_bottom`, `night_line`, `night_glow`), 노을(`dusk_stops` 3색, `dusk_ink`), 강조색 4개, 전환 워시 색 3개.
- **고르는 법**: `config.py`에 `PAL_DEFAULT = '<팔레트>'`, 장면별로 `PAL = {'<art_theme>': '<팔레트>'}`. 대본 내용(장소·재료·분위기)으로 고른다. **팔레트는 뼈대(2026-10-16)**: 장면·단위마다 바꾸거나 색을 더해도 된다(개수 제한 없음, `pal` 밖의 색도 내용에 맞으면 사용).
- `PLAN=1`이 모든 단위에 `pal`을 넣는다. 사물 고유색(피부·동물·식물·물)은 등장인물 시트를 따르되 팔레트와 어울리게. 전환 워시도 장면 팔레트를 따른다.
- `PAL_DEFAULT`가 없으면 `sunset`이 나오고 `PLAN=1`이 경고한다. **새 영상은 반드시 고른다.** 색 값은 내가 정한 것이며 `palettes.py`에서 고친다.
- 썸네일도 영상 팔레트(16-6 4번).

### 3-6. 화면 텍스트 (사용자 결정 2026-10-11: "이미지에 자막만 나오는 영상인데 대본에 따라 적절한 텍스트를 넣자")

그림에는 글자를 그리지 않고 빌더(`tools/build3.py`)가 HTML 층으로 올린다. 그림 에이전트가 사이드카 JSON `labels`(0~3개)에 적는다(`tools/art_spec.md` 8절).

- **이름 라벨 `name`**: 화면의 생물·장소·시대·물건 이름을 그 단위가 말할 때. Fredoka 34px 둥근 알약(종이 배경: 크림 바탕+팔레트 먹색 글자·테두리 / 밤·노을: 반투명 검정+흰 글자), 대상까지 얇은 선과 점, 대상 옆 빈 곳.
- **숫자 배지 `num`**: 숫자·연도·크기·비율을 말할 때. Fredoka 44px 대문자, 왼쪽에 강조색 막대, 왼쪽 위 고정(가로 x 80·y 64, 세로 x 100·y 330).
- **말풍선 `say`**: 동물·이름 없는 사람·사물의 짧은 반응. Patrick Hand 42px, 흰 바탕 검은 테두리, 꼬리가 입을 가리킴.

1. **사실은 대본에서만**: 라벨은 그 단위 내레이션의 단어(대소문자 무시), 배지는 그 단위에서 말한 숫자("four", "two and a half"처럼 말로 한 것 포함)만.
2. **말풍선은 사실을 말하지 않는다**: 4단어·24자 이하, 숫자 없음, 감정·반응만("Still here!", "Hmm?"). 실존 인물·조롱 금지. 단위의 약 1/3(사용자 결정 2026-10-22: 말풍선을 더 자주, 예전 1/8). 생명체뿐 아니라 사물(열쇠·모래시계·우주선·비커 등)도 말한다. 한 단위에 풍선 최대 2개(두 대상이 주고받을 때). 같은 말을 이웃 단위에서 반복하지 않는다.
3. **빈도(채널 결정)**: 단위의 약 절반에 1개 이상. 라벨은 처음 나올 때만(이웃 반복 금지), 배지는 숫자를 말하는 단위마다. 칠판에는 없음.
4. **시각**: 사이드카 `word`를 말하기 0.1초 전 0.25초 팝인, 컷 끝까지(`word` 없으면 컷 시작 약 0.4초 뒤). **읽는 시간 보장(2026-10-22 사용자 지적: 읽기도 전에 전환이 시작됨)**: 라벨·말풍선은 다음 그림의 전환이 시작되기 전에 읽을 시간(최소 1.5초, 단어당 +0.45초)만큼 완전히 보여야 한다. 말하는 단어가 너무 늦으면 그보다 일찍 팝인한다(빌더가 계산, `build3.py`). 배지는 왼쪽에서 0.3초 들어오며 첫 숫자가 0부터 0.9초 카운트업(형식 유지, `1000`~`2100` 연도는 세지 않음). 배지 유지는 20-2.
5. 라벨·말풍선은 그림과 함께 움직이고 글자 크기 유지, 배지는 화면 고정.
6. **안전 영역**: 가로 x 120~1800, y 80~860, 로고 모서리(x 1660 이상, y 190 이하) 금지 / 세로 x 100~940, y 300~1400. 얼굴·가운데 물체·말하는 대상을 가리지 않는다. 배지 단위는 그림 왼쪽 위(약 640×160)를 비운다.
7. **글자 수**: 이름 28자, 배지 26자, 말풍선 24자 이하.
8. **검사**: `labels_lib.check`가 빌드 때 1~7을 검사하고 어기면 멈춘다. 미리보기 `python3 tools/labelshot.py <슬러그> <미리보기 폴더> <uid…>`. 말풍선 내용·가림은 눈으로.

### 3-7. 우주 모드 (사용자 결정 2026-10-12: "우주과학 대본은 좀 더 화려한 느낌의 화풍과 우주의 아름다움을 보여주는 이펙트·색감·효과음이 필요")

우주과학 대본에만. `config.py`에 `STYLE = 'cosmic'` + `PAL_DEFAULT`(장면별 `PAL`). 그림 명세 `tools/art_spec.md` 11절(충돌 시 우선).
- **화풍(면과 빛 + 얇은 스케치 선)**: 배경 밤 70% 이상(종이·노을은 도입·결말 일상 장면만). 성운 층 = 방사형 그라데이션 3~4겹(캔버스의 40~90%, `accents`·`night_glow`, 불투명도 0.15~0.55, 가장자리 투명, 블러 필터 금지). 별 3단계 = 작은 별 120~250개, 반짝이는 중간 별 12~25개(`mv-glint-s1~s3`), 십자 광채 큰 별 2~4개(가운데 물체·핵심 대상은 피함). 천체 = 방사형 그라데이션 두 겹(본체+대기 글로우), 한쪽 림 라이트, 해칭 몇 줄, 얇은 윤곽선은 주인공 천체만. 3-2·3-6은 그대로.
- **모션**: `mv-glint-s*`, `mv-drift-nebula`(±25px, 20초), `mv-orbit-*`, `mv-pulse-core`. 장면당 `mv-` 4~8개. 속도선 20-3.
- **팔레트**: `nebula`(성운·은하, 자홍+청록), `aurora`(대기·자기권·태양풍, 초록+파랑), `deepfield`(먼 은하·블랙홀, 남색+금), `solar`(태양·초신성, 적황+흰색). `space`는 차분한 별하늘용.
- **효과음(음정 없음)**: `sparkle`, `bloom`, `starfall`, `pulse`, `warp`(0.3초), `glimmer`. 단위의 35~45%, 연속 두 컷 같은 이름 금지. 파도 같은 소리 금지: `riser`·`sweep` 삭제, `hush`·`breath`·`wind`·`rain`·`swish`도 우주 영상에서 쓰지 않는다(`bloom`이 파도처럼 들리면 입자형으로).
- **배경음악**: `bgm_lib.synth_cosmic`(코드 변경 12초, 3중 디튠 패드, 느린 고음 아르페지오, 지연 에코, 250Hz 고역통과·6.5kHz 저역통과). 덕킹·음량은 9-4.
- **길이 (2026-10-12: "20분 제한 없어")**: 9-2·12-1의 단어 수 제한 없이 대본 길이 그대로(줄이거나 늘리지 않고, 분당 약 163단어로 계산해 알림). 사실 확인은 그대로. 렌더는 영상 길이의 약 3.75~3.9배라 한 작업(300분)이면 약 60분 영상까지(병렬 20-7). 그림 분당 약 13장(에이전트로 나눔), 챕터는 약 1.5~2분당 하나, 숏츠 3편은 그대로.
- 확인하지 못한 것: 우주 모드 그림의 실제 모습, 성운 그라데이션 렌더 속도.
