## 16. 유튜브 썸네일

**본편 장면 그림을 쓰지 않고 썸네일 전용 그림을 새로 그린다.** 서로 다른 소재의 **3장(A, B, C)**(2026-10-16), 규칙은 16-6(16-2와 다르면 16-6 우선).

### 16-1. 규격
- 16:9, **1920×1080 PNG**, **2MB 이하** **(채널 결정, 모바일 업로드 한도 2MB)**. YouTube 권장 3840×2160·최소 폭 640px(확인일 2026-10-08).
- 파일명 `<슬러그>_thumbnail_A.png`, `_B.png`, `_C.png`.

### 16-2. 구성
- **글자 규격**: 영어 2~5단어(배치는 16-6 1번), Fredoka Bold(대체 Baloo 2 Bold, Nunito ExtraBold), 흰 글자 + 굵은 짙은 외곽선, 핵심 낱말 하나만 노랑 `#F2D27A`. 밝은 배경에서 외곽선이 글자 구멍을 메우면 외곽선 없는 먹색 글자도 된다. 제목을 그대로 반복하지 않고 숫자·주장은 대본에 있는 것만.
- **시선 끌기 (2026-10-16)**: 놀라게 하기보다 화려함이나 누구나 아는 이미지(영화·책·사진·유튜브도 됨, 예: 창백한 푸른 점, 허블 딥 필드, 지구돋이)의 오마주. 구도·발상만 빌려 직접 다시 그린다(배우 얼굴·캐릭터·로고·제목 글자 금지, NASA 공개 사진·저작권 끝난 작품은 가깝게 따라 그려도 됨).
- **고르게 하지 않는다 (2026-10-17)**: 내가 세 장을 골라 만들어 영상과 함께 Drive에 올린다(확인 절차 16-6 8번).
- 불쾌한 장면(신체 훼손·피·시신)은 은유 사물로(구멍 뚫린 뇌, 금지 표시가 덮인 접시).
- 로고 없음, 오른쪽 아래(영상 길이 표시)에 글자·핵심 그림 금지 **(채널 결정)**. 한글·참고 채널 이름 금지.
- **거절된 방식**: 굵은 만화풍 우주비행사, 빨간 X, 거대한 빨간 글자(2026-10-16), 작고 평평하고 빛 없는 단순 도형(2026-10-18).

### 16-3. 만드는 방법
1. 그림에는 글자를 넣지 않고, 문구는 HTML로 올린다.
2. 그림은 SVG(이미지 생성 도구가 있으면 3-4 템플릿 + `thumbnail composition, one large subject, clear focal point, space for short text on one side`).
3. HTML 한 장(1920×1080)에 그림+문구, Chromium으로 PNG 캡처(`tools/thumb_shot.py`, `thumb/A.html`~). 외부 CDN·폰트 링크 금지, 글꼴은 로컬 Fredoka Bold(npm `@fontsource/fredoka`).
4. 확인: 2MB 이하·1920×1080, 가로 320px로 줄여 판독, 오른쪽 아래 비움, 한글·철자 오류 없음.
5. 시안별 문구와 소재가 대본의 어디서 왔는지 한 줄씩 기록. 대본 내용이 사실과 다르면 문구에 쓰지 않는다.

### 16-4. 하지 않는 것
- 영상에 없는 내용을 약속하는 낚시성 문구.
- 실존 인물 얼굴, 유명 캐릭터·로고, 폭력·선정적 장면.
- 대본에 없는 숫자와 출처.

### 16-6. 반응 좋았던 썸네일에서 뽑은 규칙 (사용자 2026-10-18: "반응 좋은 썸네일 4개야 규칙 찾아서 지침서에 만들고 이 방식으로 썸네일 3개씩 뽑는 걸로 수정해")
기준 4장(이 채널): ① `AN INVISIBLE WALL`(바다 위 우주선, 하늘 끝 벽, 계단 끝 빛나는 문) ② `3 HOURS = 23 YEARS`(거대한 파도, 작은 우주비행사, 고리 달린 블랙홀) ③ `IT FEEDS THE DEEP`(심해 고래 뼈와 게·벌레) ④ `A PROTEIN THAT KILLS`(구멍 뚫린 보라색 뇌, 네온 나선 단백질, 붉게 꺾인 단백질). **그림에서 읽은 공통점이며 반응 수치를 확인한 것은 아니다(사용자 평가를 따름).**
1. **글자**: 2~4단어를 2~3줄로 쌓아 왼쪽 위에 크게(폭의 45~55%). 연결어(`AN`, `THE`, `THAT`, `A`)는 따로 한 줄, 핵심 낱말이 가장 크다. 스타일은 16-2. 문구는 대본 사실에서 뽑은 궁금증 문장이나 등식·숫자 대비.
2. **그림 = 영화 오마주 또는 직관형 한 장면**(2026-10-18: "재미가 없고 시선을 끌 만하지 않으면 안 돼"; ①=트루먼 쇼, ②=인터스텔라, ③④=직관형). **영상마다 오마주형 1~2장 + 직관형 1~2장.** 오마주형은 아는 영화·사진·그림의 구도·발상을 주제에 실제로 닮은 장면으로 바꾼다("어, 저 영화!" → "근데 왜 여기에?"). 직관형은 글 없이 그림만으로 뜻이 보인다. 요소 3~4개 이하, 대상은 화면 절반 안팎, 여백 넉넉히, 글자 영역 비움.
3. **스케일**: 맞으면 아래쪽에 작은 인물(우주비행사, 우주선).
4. **색은 대본 내용으로, 팔레트는 뼈대**(3-5; 2026-10-18: "그라데이션 밤하늘·바다는 아니야"). 주제 팔레트(`tools/palettes.py`)는 출발점일 뿐이고 그림 에이전트가 소재에 맞게 색을 바꾸거나 더해도 된다. 초점 대상이 배경보다 훨씬 밝거나 선명하게(후광 가능), 포인트 색은 금 `#F2D27A` + 보색 하나. 지평선은 높이의 65~80%, 그 아래 더 어둡게.
5. **완성도**: 크고 디테일한 대상(음영, 가장자리 빛, 질감, 소품), 분명한 빛 방향·후광, 앞·중간·뒤 깊이, 큰 대비. 네온 윤곽·얇은 밝은 윤곽선 가능.
6. 오른쪽 아래 비움, 글자와 핵심 그림 겹치지 않음. 7. 세 장은 소재·대상 위치·글자 형식(질문형, 등식·숫자형, 선언형)을 다르게.
8. **Opus 에이전트가 만든다**(2026-10-18, 지시문 `tools/briefs/thumb_art.md`): 영상마다 에이전트 1명이 3장 + 접촉 시트 1장으로 확인, 8줄 이내 보고 → **사용자에게 접촉 시트로 보이고 통과/수정 답을 받는다(필수, 2026-10-22)** → 통과한 뒤에만 Drive 업로드. 확인 전에는 그림·렌더·업로드 금지. 순서는 TTS 다음, 그림 앞(12-1). 캡처 `tools/thumb_shot.py`(A~F).

### 16-7. 2026-10-18 제작 기록 (Opus 에이전트, 접촉 시트·320px 판독 확인; 영상 내용은 직접 보지 않음)
- 통과한 12장: dinosaur-restorations A~C, desert-oasis A~C, left-handed-ten-percent A~C, paleozoic-chronicles D~F(문구·유형 표는 archive). 한 영상(3장)당 에이전트 1명, 약 5~10분, 토큰 약 11만~14만.
- **이미 쓴 오마주(다른 영상에서 다시 쓰지 않음, `tools/briefs/thumb_art.md` 목록)**: 죠스, 쥬라기 공원, 아라비아의 로렌스, 라이온 킹, 록키, E.T., 아담의 창조, 트루먼 쇼, 인터스텔라.
- **업로드**: 사용자가 통과시킨 뒤에만. 썸네일만 올릴 때 `render/<슬러그>/.deliver_only`(빈 파일) + `render/.slug`(슬러그 한 줄씩) 푸시 → `render.yml`이 `deliver/`만 올림. 확인 뒤 `.deliver_only`를 지우고 `.slug`를 `none`으로 되돌려 푸시.
