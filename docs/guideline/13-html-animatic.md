## 13. HTML 애니메틱 규격

컷·자막·칠판·효과음 타이밍을 확인하는 재생 가능한 시안. 단일 HTML.

### 13-1. 화면 구성
1920×1080 스테이지를 폭에 맞춰 축소(층: 그림 → 옅은 종이 질감 → 로고 → 자막). 컨트롤: 재생/일시정지, 이전·다음, 시간, 장면 경계 타임라인(칠판 초록, 클릭·드래그), 효과음 켬/끔, 로고 불러오기, 전체화면, 장면 목록, 현재 장면 패널(내레이션·효과음·프롬프트 복사), Space·←/→. 스테이지 밖 한국어, 안 영어. 첫 프레임에서 정지 상태로 시작.
### 13-2. 장면 그림
3장 화풍 SVG(`<filter>` 금지), 컷마다 새 그림, 인물은 시트대로.
### 13-3. 모션과 전환
4-1 반복 애니메이션·카메라(칠판은 없음). 애니메틱은 하드컷만. 일시정지·이동 시 그 시점 모습.
### 13-4. 자막 타이밍
줄 시각 = 컷 길이 × (앞 단어 수 ÷ 전체 단어 수), 컷 길이 = 단어 수 ÷ 2.7초. MP4는 15-2·21-5.
### 13-5. 칠판
7장 규격의 HTML 요소, 팝인 시각은 13-4 방식.
### 13-6. 효과음
9-3 큐를 Web Audio로 합성. 재생 후부터, 컷이 바뀌면 배경음 약 30ms 안에 교체, 포인트음은 큐 시각에 한 번.
### 13-7. 로고
6장 위치, 파일 선택으로 불러와 브라우저에 기억, 없으면 점선 원.
### 13-8. 음성
내레이션 음성은 넣지 않는다(페이지 메모에 적음).
### 13-9. 게시 전 확인
모든 장면을 렌더해 오류·겹침·잘림·자막 길이 확인. 게시 후 채팅에는 한 문장만.
