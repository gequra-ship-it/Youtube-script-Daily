## 17. 제목 · 설명 · 타임라인 · 해시태그 (2026-10-24 개정: 짧게, 이 네 가지만)

`<슬러그>_metadata.txt` 한 파일. 내용은 **제목, 영상 설명, 타임라인, 출처, 해시태그**다(출처는 사용자 지시 2026-10-24로 유지). 한국어 안내문·채널 소개(ABOUT) 문구는 넣지 않는다(사용자 결정 2026-10-24: 예전 분량의 약 1/3). 모두 영어. 생성 `tools/gen_text.py`(대본 txt와 렌더 리포트는 더 이상 넘기지 않는다, 아래).

### 17-1. YouTube 공식 한도 (2026-10-09 확인)
- 제목 100자, 설명 5,000자 이하.
- 챕터(타임라인): 첫 타임스탬프 `00:00`, 오름차순 3개 이상, 하나 10초 이상. 직접 넣은 챕터가 자동 챕터보다 우선.
- 해시태그: 공백 없음, 제목 옆 최대 3개, 60개를 넘으면 모두 무시.
- 설명은 앞부분만 "더보기" 전에 보인다.

### 17-2. 파일 형식 (고정)
```
=== TITLE ===
<제목 한 줄>

=== DESCRIPTION ===
<1~2문장, 약 260자 이하>

TIMELINE
00:00 <챕터 제목>
00:48 <챕터 제목>
...

SOURCES
- <대본·칠판이 밝힌 출처>

#MiyasNote #<해시태그> #<해시태그> ...
```
숏츠는 TIMELINE 없이 제목·설명·(출처)·해시태그. SOURCES는 대본이나 칠판 `Source:`가 밝힌 출처가 있을 때만 쓰고 없으면 블록을 뺀다(지어내지 않는다).

### 17-3. 항목별 규칙
- **제목 (사용자 결정 2026-10-24)**: **짧고 한눈에 관심을 끌 것. 질문형일 필요 없다.** 직관적으로 말하거나 은유적으로 쓰거나 둘 다 가능하고 하나로 고정하지 않는다. **약 50자 이하**(모바일 피드는 약 40자까지 보임, 50자는 제안값), Title Case, 이모지·전부 대문자 금지, 핵심 단어를 앞에. 영상에 없는 내용을 약속하지 않고, 썸네일 문구를 반복하지 않으며, 숫자는 대본에 있는 것만. 예(구조 확인용): `Why Deep Sea Creatures Grow Into Giants`(직관), `The Alien Living in Our Oceans`(은유).
  - 검사: `python3 tools/title_lint.py --title "..." --thumb "..."`(길이 50자·Title Case·이모지·과장어·썸네일 중복·썸네일 2~4단어; 참고용). 도구 출처: youtube-agent-skill(MIT) `yt-package`.
- **설명 (사용자 결정 2026-10-24)**: 1~2문장, 약 260자 이하(`gen_text.py`는 `DESC`의 첫 문단만 쓰고 넘치면 경고). 영상의 핵심 질문이나 가장 의외인 사실(대본에서).
- **타임라인**: 롱폼(15분 이내) 기준 5~10개, 영어 Title Case 5단어 이하, **렌더 MP4의 실제 컷 시작 시각**(`mm:ss`). 모두 10초 이상, 첫 챕터 `00:00`. 시각이 렌더 구성표(내레이션 배치 시각)에서 온 값이고 렌더된 MP4로 다시 재지 않았다면 채팅 보고에 "추정"이라고 적는다.
- **해시태그**: 4~5개, 설명 맨 아래 한 줄. 첫째는 항상 `#MiyasNote`(0장 7번의 예외), 그다음 가장 중요한 주제어 둘, 나머지 주제어(CamelCase).
- 한글·이모지·대문자 남발·키워드 덤핑 금지. 사실 확인은 12-1과 같다.

### 17-4. 사용자에게 넘기는 것 (2026-10-24)
영상(MP4), 썸네일, 메타데이터 txt만. **대본 txt(`_script.txt`)와 렌더 리포트(`_render_report.txt`)는 넘기지 않는다.** `gen_text.py`는 대본 참고본을 작업 폴더(`<WORK>/<슬러그>/build/`)에만 만든다. 렌더 리포트는 Actions 로그에만 남고 Drive에는 올라가지 않는다(워크플로 업로드 줄 제거 확인, 2026-10-25).
